# Дартс: дуэль

Браузерная логопедическая игра для педагога и ребёнка. 10 раундов, по одному броску каждого игрока в раунде. Речевой материал задаёт педагог. Таймера нет.

## Запуск

Откройте `index.html` в браузере или разместите `index.html` и `game.js` рядом на статическом хостинге. Сборка, зависимости и внешние сервисы не нужны. Звук синтезируется локально, мишень и дротики создаются SVG и CSS, фон игровой комнаты находится в assets/playroom.jpg. Данные игроков никуда не отправляются. Счёт хранится до выхода в меню или перезагрузки; настройка звука сохраняется локально.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch → main → / (root) → Save. Адрес: https://propodgotovkaa-creator.github.io/drotiki/

## Genially / iframe

После включения Pages:

```html
<iframe src="https://propodgotovkaa-creator.github.io/drotiki/" title="Дартс: дуэль" width="100%" height="850" style="border:0;border-radius:16px" allow="autoplay" allowfullscreen></iframe>
```

Для узких экранов оставляйте вертикальную прокрутку iframe. В ограниченном iframe необходимо разрешить выполнение скриптов. Игра не требует доступа к странице-контейнеру.

## Механика

Нажмите на любой дротик — он сразу летит в мишень. После результата нажмите «Передать ход». Бросок следующего игрока не запускается автоматически. Результаты по всем раундам доступны на финальном экране.

Классический порядок 20 секторов. Геометрия рисунка и расчёта общая: внешний узкий пояс ×2, внутренний ×3, зелёный центр 25, красный 50, за игровым полем 0. Для всех цветов и обоих игроков одинаковый генератор: 3,5% — красный центр, 7% — зелёный, 5% — промах, остальные — равномерно по площади остальной мишени. Победитель не задан заранее.

Поддержаны мышь, сенсорный экран, клавиатура, уменьшение анимаций согласно настройке устройства, выключение звука. Повторные нажатия во время полёта и начисления блокируются.
